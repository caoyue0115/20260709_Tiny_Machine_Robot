# 成语接龙十五加十秒余额制设计

日期：2026-07-16
状态：用户已确认

## 目标

将现有 `25/20/30/60` 多套空闲计时收敛为每轮固定的有效尝试余额：

```text
基础余额：15秒
首次提示后的补救余额：10秒
每轮有效尝试总余额：25秒
```

余额只计算用户可交互阶段：本地 VAD等待、active turn录音与等待 ASR/轮次结果。机器人音频播放和播放后的200ms回声保护不消耗余额。

## 余额状态机

机器人有效回复播放完成并经过回声保护后，开始新一轮，余额为15秒，`rescue_active=false`。

基础阶段：

- 15秒余额耗尽且从未触发 VAD：播放“你还在吗？”，增加10秒补救余额，进入补救阶段。
- VAD后得到 `meaningful`：播放正常回复，重新获得新一轮15秒基础余额。
- VAD后得到 `empty / invalid / off_topic`：不播放服务器无效回复，统一播放一次本地“我没听清，请再说一次”，在当前剩余基础余额上增加10秒，进入补救阶段。
- 若 active turn 的超时债务已经耗尽新增的10秒，则直接在安全边界退出，不连续播放“我没听清”和退出提示。
- 显式退出：立即结束。

补救阶段：

- VAD等待、录音和等待轮次结果持续扣减同一份余额。
- 若一个 active turn 在余额即将耗尽时开始，超出的处理时间保留为负余额；首次补救的10秒先抵扣该超时债务，不能因为等待ASR而把总尝试时间延长到25秒以上。
- `empty / invalid / off_topic` 全部静默，不再增加余额，不重复提示。
- 连续噪声造成多轮无效 ASR只能消耗余额，不能刷新或延长。
- `meaningful` 取消退出，播放正常回复并开始新的15秒基础阶段。
- 余额耗尽时不再创建新 ASR；若已有 active turn，则允许安全结束。其最终结果为 `meaningful` 时仍可成功恢复，否则在首个安全边界退出。
- 显式退出立即结束。

## 三条等价路径

```text
完全无声：15秒 + presence提示 + 10秒 = 25秒有效尝试
第3秒首次无效：已用3秒 + 剩余12秒 + 补救10秒 = 25秒有效尝试
第12秒首次无效：已用12秒 + 剩余3秒 + 补救10秒 = 25秒有效尝试
```

提示音与回声保护暂停余额，因此墙钟时间会比25秒多出提示播放时间和回声保护；ASR录音及等待判定属于用户交互处理时间，继续消耗余额。

## ASR边界保持不变

本次不修改游戏音频采集的终止条件、Opus协议或云端 ASR生命周期：

```text
VAD确认
→ utterance_start
→ 上传200ms pre-roll与实时Opus
→ 连续约200ms尾静音，或总音频达到约4秒
→ utterance_end
→ 等待ASR final或超时
→ 销毁本轮ASR
```

只允许调整游戏专用 VAD等待函数的单次等待上限，使最后一次等待不超过当前剩余余额。空闲期间仍只有本地 VAD，没有音频上传或云端 ASR。

## 提示预算

每轮最多播放一条挽救提示：

- 基础15秒完全静默：只播放“你还在吗？”。
- 基础阶段首次空或无效：只播放“我没听清，请再说一次”。
- 进入补救阶段后的空、无效、无关或噪声结果全部静默。

自动退出时仍播放“那我们下次再玩吧”，发送 `idle_exit`，清除当前 `device_id` 游戏状态，关闭游戏 WebSocket并恢复 WakeNet。

## 结果分类

| 结果 | 行为 |
|---|---|
| `meaningful` | 有效成语、重复、难度切换；播放正常回复并重置15秒基础余额 |
| `empty` | 三种现有可恢复空ASR错误；基础阶段提示一次，补救阶段静默 |
| `invalid` | 基础阶段改播本地没听清提示，补救阶段静默 |
| `off_topic` | 基础阶段改播本地没听清提示，补救阶段静默 |
| `exit` | 播放必要退出音频并立即结束 |
| 缺失旧字段 | 保持现有兼容行为，视为旧版成功轮次并重置15秒 |
| 基础设施错误 | 不冒充没听清，不增加余额；已消耗的等待时间仍计入余额 |

## 固定参数

| 参数 | 值 |
|---|---:|
| 基础余额 | 15秒 |
| 首次提示补救余额 | 10秒 |
| 每轮最大有效尝试余额 | 25秒 |
| 播放后回声保护 | 200ms，不扣余额 |
| 空结果提示最早时间 | VAD确认后1.5秒 |
| 常规VAD检查窗口 | 最多3秒，最后一窗缩短到剩余余额 |
| idle_exit ACK等待 | 最多2秒 |

删除原 `25秒 normal`、`20秒 post-presence`、`30秒 post-nonmeaningful` 与 `60秒 noise hard deadline`。新余额制取代四者。

## 测试要求

- 静态守卫确认基础和补救常量分别为 `15000` 与 `10000`，旧时间常量全部消失。
- VAD等待、录音和等待轮次结果扣减余额；播放与回声保护不扣减。
- 基础余额耗尽播放 presence并只增加一次10秒。
- 基础阶段首次 `empty / invalid / off_topic` 统一使用本地 misheard PCM并只增加一次10秒。
- 补救阶段重复非有效轮次不播放、不增加余额。
- `meaningful` 清除补救状态并重置15秒。
- 最后一次游戏 VAD等待不超过剩余余额。
- ASR的200ms尾静音与约4秒上限保持现有实现与测试不变。
- `device_id`、`turn_id`、退出 ACK和 WakeNet恢复行为保持不变。
